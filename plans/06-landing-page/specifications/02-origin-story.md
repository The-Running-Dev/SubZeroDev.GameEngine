# Origin Story

## The truthful version

This project did not begin with a grand vision.

It began because the author missed *Jones in the Fast Lane*.

One evening, mostly as a joke, he asked an LLM to explain how the game worked.

The LLM described:

- jobs
- education
- money
- needs
- time
- movement
- purchases
- random events
- progression
- interactions between systems

Then it began suggesting implementation details.

That should have been the end of the story.

Instead, one question appeared:

> If I am already writing this, why would I write it for only one game?

The mechanics were not unique to *Jones in the Fast Lane*.

Jobs, education, schedules, resources, needs, progression, relationships, events, and world state were reusable concepts.

The next question was inevitable:

> If one mechanic is reusable, what else is?

The project escalated from:

```text
I miss Jones.
```

to:

```text
How does it work?
```

to:

```text
I could prototype that.
```

to:

```text
Why make it specific?
```

to:

```text
These mechanics are reusable.
```

to:

```text
The simulation should be deterministic.
```

to:

```text
Humans and AI should submit the same validated commands.
```

to:

```text
Apparently I am writing a game engine now.
```

## Narrative value

This origin story is stronger than a manufactured company story because it is:

- honest
- funny
- technically meaningful
- relatable to modern AI-assisted development
- consistent with the author's personality
- a natural explanation of why the engine exists

The origin should not be hidden on an About page.

It should be part of the homepage.
