## Method

Every open issue as of this freeze was read in full and checked against the current tree (grep for
the named symbols/files, `git log -S` for the introducing commit) or against
`design/90-decisions.md` for a canonical decision. An issue was closed only when every Done-when box
or every "Ask" bullet was independently confirmed true against current `main` — not from the issue's
own claims. Issues with only partial evidence (e.g. #237) were left open with the gap noted rather
than closed on partial credit.

Closed engine issues (W93–W105 range and earlier) were spot-checked via `tools/Test-DesignDrift.ps1`
(reports "No drift" — 61 slices compared, 0 findings, 0 could-not-evaluate) rather than individually
re-read; a full manual re-audit of every closed issue's evidence was judged disproportionate to this
unit's scope and is not what W106.2 asks for (it governs closing *open* issues, not re-litigating
closed ones).
