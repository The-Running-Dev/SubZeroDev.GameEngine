# SubZeroDev Game Engine Landing Page Specification Bundle

This bundle defines the creative direction, user experience, content, visual system, Docusaurus implementation, motion design, and implementation plan for the SubZeroDev Game Engine landing page.

The central idea is simple:

> Build mechanics once. Create infinite games.

The page should not feel like a conventional software landing page or documentation portal. It should feel like a beautifully designed, slightly absurd technical essay that gradually reveals a serious deterministic simulation architecture beneath a deadpan origin story.

The project began with a mundane question about *Jones in the Fast Lane*. An LLM explained the mechanics, then started suggesting implementation details. That led to the question:

> If I am already writing this, why would I write it for only one game?

That question escalated into a reusable deterministic game engine.

The landing page must preserve that truth rather than inventing a polished startup myth.

## Non-negotiable principles

- The homepage is not documentation.
- The homepage is the story of the project.
- The underlying engineering must remain credible.
- Humor must be dry, sparse, and earned.
- The page must not look like generic SaaS marketing.
- The visual design should rely on typography, spacing, and restrained motion.
- The phrase `Well... why not?` remains.
- Documentation becomes progressively more serious as the visitor goes deeper.
