## vocabulary
`AGENTS.md` is named `CLAUDE.md` here — every `AGENTS.md §` citation this command emits should
resolve through that file's real section names (e.g. the routing table lives under *The Agent
Kit — Canonical Workflow*, not a section literally named "Command routing"); never emit a section
name you have not seen in `CLAUDE.md` itself. Slice ids use the retained `W<n>` scheme, so
`/slice S<n>` in the routing table reads `/slice W<n>` here.
