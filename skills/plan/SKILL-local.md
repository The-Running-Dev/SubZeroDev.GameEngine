## vocabulary
`AGENTS.md` is named `CLAUDE.md` here. This repository retains its established `W` prefix — do
not renumber existing units to `S`; every `S<n>` heading and id below (`S<n>.1`, `S3.1`, …) reads
as `W<n>` here. Existing per-unit numbering already goes one level deeper than a bare `.1`/`.2`
(e.g. `W3a`) — extend that scheme rather than introducing a second one.
